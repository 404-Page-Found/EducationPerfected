THE TOOLKIT

Less window juggling.
More control.

One shared engine, whether you prefer a window, an on-page panel, or the terminal.

01 / WORKSPACE

A browser, already there.

The OS installers include the desktop app and its embedded browser. Open the app, sign in, and choose a task. No separate Node.js install or terminal setup for the desktop route.

Desktop appEmbedded browserOptional saved login
02 / TASKS

Support with boundaries.

Word-to-word, listening, dictation and supported Smart Lesson question types. Dash choice and typed rounds have fixture coverage, not a full live sprint verification.

See the support matrix ↗
03 / CONTROLS

You set the pace.

Start and stop, refresh a task's word list, switch between auto and semi-auto, and adjust pacing and optional first-try accuracy simulation. Semi-auto leaves submission to you.

Explore the controls ↗
04 / EVERYDAY USE

Keep the essentials close.

An on-page control panel, a terminal CLI, and optional login storage in the OS credential store. Installed desktop apps can check for updates from Settings.

Settings & storage ↗

CLEAR EXPECTATIONS

A continuation.
Not a guarantee.

EducationPerfected continues the archived project by akioweh. It is an independent hobby project, not made, endorsed or supported by Education Perfect.

Read the full disclaimer ↗

Tested does not mean universal.

The word-to-word flow has run end to end on the live service. Other types have bounded live checks or synthetic coverage. Dash has no end-to-end live verification.

Unsupported means stop.

Assessments and unsupported shapes are refused rather than guessed at. Service changes can still break a supported flow or leave an incomplete answer.

Your account. Your responsibility.

Automation may be detected, marked wrong, or acted on. It is not recommended for homework. Use only where you have permission and supervise it while it runs.
